## 연결 순서

### 1. 스냅샷 시트 연결
1. Looker Studio → 만들기 → 데이터 소스 → **Google 스프레드시트**
2. 위 4개 시트를 각각 데이터 소스로 추가
3. 필드 타입 확인:
   - `기간시작`·`기간종료`·`날짜` → **날짜(YYYY-MM-DD)**
   - `전환율`·`참여율`·`CTR`·`비중` → **숫자 → 백분율**
   - `지출원`·`시세조회CPA`·`견적등록CPA` → **숫자 → 통화(KRW)**
   - `단계순서` → 숫자 (퍼널 정렬용)

### 2. 라이브 소스 연결
- **GA4**: 커넥터에서 속성 `499270625`(drrrk.ai.kr), `522968350`(loan.drrrk.ai.kr) 선택. 무료·공식
- **메타 광고**: 공식 무료 커넥터 없음. Supermetrics·Windsor.ai·Catchr 등 유료 파트너 커넥터 필요 (월 과금). 예산이 없으면 **월 1회 이 시트를 수동 갱신**하는 편이 낫다

## 권장 대시보드 4장

### 1장. 퍼널 (소스: 퍼널_팩트)
- **막대그래프**: 측정기준 `단계`(정렬 = `단계순서` 오름차순), 측정항목 `인원`, 필터 `축 = 전체`
- **기간 비교**: `기간구분`을 필터 컨트롤로 → 7월전체 / 전반기 / 후반기 / 클린윈도우 전환
- ⚠️ 기본값은 **클린윈도우**로 둘 것. 7월전체는 랜딩 버그 기간이 섞인 하한값

### 2장. 채널 (소스: 퍼널_팩트)
- **가로 막대**: 측정기준 `축값`, 측정항목 `전환율`, 필터 `축 = 채널` AND `단계 = AI시세조회`
- **표**: `축값` × `방문수`·`인원`·`전환율`, `채널그룹`으로 색상 구분
- 핵심 시각화: 인스타 오가닉 44.6% vs ig/paid 2.19% 대비

### 3장. 랜딩 수정 효과 (소스: 일별_트래픽)
- **시계열**: X축 `날짜`, Y축 `평균체류초`, 색상 `채널`
- **기준선**: 2026-07-21에 참조선 추가 (`랜딩수정후` 필드로 색 구분도 가능)
- ig/paid 1.99초 → 42.2초 변화가 한눈에 보임

### 4장. 광고 효율 (소스: 메타광고)
- **표**: `구분` × `지출원`·`AI시세조회`·`견적등록`·`시세조회CPA`
- **필터**: `분석축`으로 소재별/캠페인유형별/연령성별 전환
- **산점도**: X `지출원`, Y `시세조회CPA`, 크기 `견적등록`

## 읽을 때 반드시 지킬 것

1. **기간을 섞지 말 것.** 7월전체와 클린윈도우는 같은 지표가 6~8배 차이 난다. 한 차트에 두 기간을 겹쳐 놓으면 잘못된 결론이 나온다.
2. **메타 수치와 GA 수치를 더하지 말 것.** 메타는 랜딩뷰 분모 + 어트리뷰션 윈도우(조회 전환 포함), GA는 세션 소스 기준 사용자수다. 같은 "시세조회"라도 정의가 다르다.
3. **연령·성별은 표본 5건(등록 기준)이다.** 대외 문서에는 비율(80%)이 아니라 실수("등록 5건 중 4건")로 쓸 것.
4. **채널별 방문수 합계가 전체(10,091)를 넘는다.** GA4는 사용자가 여러 소스에 걸치면 중복 집계한다. 채널별 비율은 정확하나 묶음 합계는 근사치다.
5. **fb/paid 0.017%는 실력이 아니다.** 랜딩 지연 버그(~5초) 기간의 수치이며, fb는 수정된 랜딩을 겪은 적이 없다. 재검증 전까지 "채널이 나쁘다"는 결론으로 쓰면 안 된다.

## 8월부터 추가될 데이터

7/31에 아래를 설정했으므로 8월 데이터부터 GA4 커넥터로 직접 조회 가능하다 (소급 불가).

- **Google Signals** — 연령·성별 (단, 시세조회 월 108명 규모에선 임계값으로 전환 세그먼트는 안 나올 수 있음)
- **맞춤 측정기준 10개** — `brand_name` `model_name` `category_id` `entry_source` `sales_type` `ai_source` `bid_count` `input_mode` `category` `source`
- **맞춤 측정항목 3개** — `price`(낙찰가) `image_count` `photo_count`

특히 `brand_name`으로 **"샤넬이 실제 시세조회 1위인가"**를, `bid_count`로 **"등록 28건에 왜 입찰이 안 붙었나"**를 8월에 직접 볼 수 있다.
