# 05. 로드맵

> 각 단계는 명시된 게이트를 통과해야 다음 단계로 넘어간다. 게이트 실패 시 피벗/중단 판단을 먼저 한다.

---

## Phase 0 — 시장 검증 (6주)

- 내용: [03-validation-plan.md](03-validation-plan.md) 실행
- 비용: 인건비 외 최소 (교통비·통신비 수준)
- **게이트: [02-business-plan 9장](02-business-plan.md) Go 조건 4개 충족**

## Phase 1 — 컨시어지 파일럿 (8주)

- 대상: 파일럿 시설 3~5곳 (장례식장 2~3 + 웨딩홀 1~2), 수거 파트너 2~3곳
- 도구: 카카오톡 채널 + 스프레드시트 + 종이 동의서 ([04-mvp-spec 7장](04-mvp-spec.md))
- 목적: 단위 경제성 실측, 플로우 검증, 유족 동의 프로세스 현장 테스트
- **게이트: 건당 공헌이익 > 0, 수거 완수율 95%+, 파일럿 시설 이탈 0**

## Phase 2 — 제품화 + 지역 확장 (3~6개월)

- 제품: 시설용/파트너용 모바일 웹 + 운영 어드민 ([04-mvp-spec 4장](04-mvp-spec.md))
- 확장: 수도권 1개 권역 밀도 우선 (물류 효율은 밀도에서 나온다 — 광역 확장 금지)
- 영업: 다지점 운영사 본사 + 상조회사 제휴 1건 성사에 집중
- 수익: 시설 구독료 + 회수 마진 본격 과금
- **게이트: 활성 시설 20곳, 월 반복 매출 발생, 상조 제휴 LOI 1건**

## Phase 3 — 자원순환 레이어 (6~12개월)

- 분해·분류 데이터화: 생화/프레임/부자재별 처리 경로 추적
- 처리 파트너십: 퇴비화·업사이클 업체 정례 계약, 프레임 재사용 풀 운영
- 인증 상품화: "투명 처리 인증" 리포트를 상조 부가서비스로 화이트라벨 공급
- **게이트: 회수 마진이 물류비의 50% 이상 커버, 인증 상품 유료 계약 1건**

## Phase 4 — 전국 인프라 + 데이터 사업

- 권역별 파트너 네트워크 복제 (권역당 밀도 게이트 재적용)
- 시설별 발생량·물류 원가 데이터 기반 동적 배차/가격
- ESG·자원순환 리포트 (공시 수요 법인 한정)
- 인접 확장 검토: 개업 화환, 행사 꽃장식, 조화(인조) 회수 등

---

## 마일스톤 요약

```text
Phase 0 (6주)     검증        → Go/No-Go
Phase 1 (8주)     컨시어지     → 공헌이익 > 0 증명
Phase 2 (3~6M)    제품+밀도    → 반복 매출, 상조 제휴
Phase 3 (6~12M)   자원순환     → 회수 마진 + 인증 상품
Phase 4 (12M+)    전국화       → 데이터 인프라
```
