# Wreath — 화환 회수 네트워크 플랫폼

> 웨딩홀·장례식장에서 반복적으로 대량 발생하는 화환을
> 전국 단위로 **회수 → 배차 → 추적 → 자원화**하는 B2B 인프라 사업 기획 프로젝트.

화환 처리는 수십 년간 지역 수거업체의 전화/수기 관행으로 처리되어 온 레거시 영역이다.
이 프로젝트는 화환을 "폐기물"이 아니라 **반복 발생하는 유가자원**으로 보고,
수거권·금전 흐름·처리 경로를 검증한 뒤 회수 네트워크 플랫폼으로 사업화하는 것을 목표로 한다.

## 한 줄 요약

> 이 사업의 성패는 "화환을 치워주는 것"이 아니라,
> **합법적 처리를 전제로도 화환 1개의 회수 경제성이 성립하는가**를 증명하는 데 달려 있다.
