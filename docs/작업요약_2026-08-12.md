## 1. 결론 요약 (한 문단)

드르륵이 중동에 이식할 것은 한국식 담보대출 마켓플레이스가 아니라 **Asset Bureau — 비정형
실물자산을 금융기관이 이해할 수 있는 데이터로 표준화하는 자산 언더라이팅 레이어**다
(NICE/KCB가 사람을 Score하듯, 드르륵은 자산을 Score한다). UAE에는 DMCC Tradeflow라는 담보
Rail이 이미 있으므로, 국내에서 증명할 것은 그 앞단인 **"예상가 → 다수 바이어 실호가 → 실제
처분가 → 회수율"의 폐쇄 루프 데이터 엔진**이다. 이 엔진은 대부업 라이선스 없이 현재의
비교견적(판매) 서비스만으로 가동 가능하며(판매 성사 = 처분 실측), 자본 0원으로 구축 가능함을
로컬 프로토타입으로 검증 완료했다.

## 2. 확정된 전략 프레임

### DRRRK = Asset Bureau (3-Layer 모델)

| Layer | 담당 | 답하는 질문 |
|---|---|---|
| 1. Collateral Rail | DMCC Tradeflow | 자산이 법적으로 존재하고 담보 설정 가능한가? |
| **2. Asset Underwriting** | **DRRRK** | **얼마이고, 얼마나 유동적이며, 얼마까지 안전하게 금융 가능한가?** |
| 3. Capital | Bank / Islamic Finance Co. | 신용심사·승인·LTV 최종 결정·자금 공급 |

- 드르륵은 lender가 될 필요 없음 (Credit Decision은 금융기관 고유 권한 — 규제 정합)
- 샤리아는 담보(Rahn)를 금지하지 않음 — 드르륵 데이터는 Conventional/Islamic 양쪽 Rail에 공급 가능
- 핵심 구분: **Market Value(소매 시세)가 아니라 Liquidation Value(회수 시 현금화 가격)** —
  드르륵의 바이어 매입 호가는 도매 호가 = LV의 직접 관측치 (외부 어디에도 없는 데이터, 구조적 해자)

### 라이선스 공백기의 재해석

파이프라인 8단계(등록→식별→추정→견적→성사가→예상vs실제 비교→축적→안전 한도) 중
**대부업 라이선스가 필요한 단계는 없다.** 중고 매입은 대부업이 아니고, 판매 마켓플레이스는
성사되는 모든 거래가 처분 실측이라 데이터 관점에서 담보대출(디폴트 건만 관측)보다 우월하다.
담보 이벤트는 라이선스 취득 후 같은 원장에 `deal_type`만 다르게 합류한다.

### Phase 로드맵

```
Phase 1.  Korea — Market Validation   (현재: 비교견적 + 드르륵에셋)
Phase 2a. Korea — Asset Underwriting  (★ 지금: 판매 데이터로 원장 + Asset Score)
Phase 2b. Korea — 담보 데이터 합류     (라이선스 취득 후)
Phase 3.  Korea — Financial PoC       (금융기관에 데이터 공급 — 라이선스 불요)
Phase 4.  UAE  — Infrastructure 확장  (DRRRK × DMCC Tradeflow × UAE 금융기관)
```

### 저거래량(하루 1~3건) 보완 3대 전략 — 자본 0원

1. **견적 자체가 데이터**: 유찰 건 포함 전량 기록 → 등록 1건 = 가격 이벤트 4~6개
2. **파트너 전당포 과거 장부 백필**: [감정가→대출→유질→처분가] 2~3년치 — 최대 레버리지
3. **외부 sold 데이터 캘리브레이션**: KREAM·Chrono24 등으로 소매 시세 기준선

### Gemini 부정확 문제의 해법

- 원인: 사진→가격 one-shot은 원리적으로 불가능 (LLM에 시세 테이블이 없음)
- 해법: **역할 분리** — Gemini는 식별·정규화만 (폐쇄형 카탈로그 매칭, 가격 필드 없는 JSON),
  가격은 원장 분위수에서만 산출 (항상 구간+신뢰도, 표본 부족 시 정직하게 "산출 불가")
- 바이어 견적 도착 = ground truth 자동 라벨링 → 역경매 구조 자체가 자기 교정 루프

## 4. 핵심 검증 결과 (시뮬레이션)

기본 실행(365일 × 하루 2건 등록, 백필 300건): 등록 703건 → 가격 이벤트 5,430건,
매입 호가 2,479건, 판매 성사 435건. 서브마리너 기준 산출 예시:
MV 1,511만 / LV 1,191만 / 도매할인 21.2% / 유질 회수율 141.8% / **권장 LTV 59.6%**.

**1차 단계(자산 식별·상태판별·정가품 판별)의 결정성 — 정량 확인:**

| 식별 정확도 | 오염 이벤트 | MAPE | Spread | 평균 권장 LTV |
|--:|--:|--:|--:|--:|
| 85% | 5.0% | 18.0% | 43.7% | 55.0% |
| 95% | 1.6% | 16.0% | 34.4% | 57.4% |
| 99% | 0.3% | 9.0% | 31.2% | **59.0%** |

식별 정확도가 오르면 원장 오염이 1/17로 줄고 추정오차가 절반이 되며,
**같은 데이터로 더 높은 LTV를 안전하게 제시할 수 있다 — 식별 정확도가 곧 금융 한도의 상한.**
(Shorooq에게 "왜 식별·정가품 인프라에 투자해야 하는가"의 정량 논거)

> ⚠ **데이터 출처**: 현재 원장은 100% 시뮬레이션 생성 데이터다. 기준 소매가(catalog_seed.csv
> 22개 모델)는 수기 근사치, 가격 움직임·호가·회수율은 가정값 기반 난수. 목적은 숫자의 정확성이
> 아니라 **실측을 채워 넣을 그릇(스키마·산식·프로그램)의 작동 검증**이며, 검증 완료됨.
> `ingest.py`로 실데이터를 넣는 순간 같은 프로그램이 실데이터 기반으로 동작한다.
